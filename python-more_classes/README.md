# Python - More Classes and Objects

Building a `Rectangle` class step by step: properties, special methods
(`__str__`, `__repr__`, `__del__`), class attributes, static methods and
class methods.

| File | Description |
| ---- | ----------- |
| `0-rectangle.py` | Empty class `Rectangle`. |
| `1-rectangle.py` | Private `width` and `height` with validated properties. |
| `2-rectangle.py` | Adds `area()` and `perimeter()`. |
| `3-rectangle.py` | Adds `__str__` to draw the rectangle with `#`. |
| `4-rectangle.py` | Adds `__repr__` so `eval(repr(r))` recreates it. |
| `5-rectangle.py` | Adds `__del__` that prints `Bye rectangle...`. |
| `6-rectangle.py` | Adds class attribute `number_of_instances`. |
| `7-rectangle.py` | Adds class attribute `print_symbol` used for drawing. |
| `8-rectangle.py` | Adds static method `bigger_or_equal(rect_1, rect_2)`. |
| `9-rectangle.py` | Adds class method `square(cls, size=0)`. |
