# Python - Classes and Objects

Introduction to object-oriented programming in Python, built step by
step around a `Square` class.

| File | Description |
| ---- | ----------- |
| `0-square.py` | Empty class `Square` that defines a square. |
| `1-square.py` | `Square` with a private instance attribute `size`. |
| `2-square.py` | `Square` with size type/value validation. |
| `3-square.py` | `Square` with a public `area()` method. |
| `4-square.py` | `Square` with a `size` property getter and setter. |
| `5-square.py` | `Square` with a `my_print()` method that prints it with `#`. |
| `6-square.py` | `Square` with a validated `position` used when printing. |
