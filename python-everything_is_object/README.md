# Python - Everything is object

Questions and small exercises about how Python handles objects:
identity vs. equality (`is` vs `==`), `id()` and `type()`, mutable vs.
immutable types, aliasing, how arguments are passed to functions, and
tuple syntax.

| File | Topic |
| ---- | ----- |
| `0-answer.txt` | Function that prints the type of an object |
| `1-answer.txt` | Function that gives an object's identifier |
| `2-answer.txt` - `5-answer.txt` | Do two integer variables point to the same object? |
| `6-answer.txt` - `9-answer.txt` | `==` vs `is` with strings |
| `10-answer.txt` - `13-answer.txt` | `==` vs `is` with lists |
| `14-answer.txt` - `15-answer.txt` | `append` vs `+` on an aliased list |
| `16-answer.txt` - `18-answer.txt` | Passing integers and lists to functions |
| `19-copy_list.py` | Function `copy_list(l)` that returns a copy of a list |
| `20-answer.txt` - `23-answer.txt` | Which expressions create a tuple |
| `24-answer.txt` - `26-answer.txt` | `is` with ints and tuples |
| `27-answer.txt` - `28-answer.txt` | `a = a + [x]` vs `a += [x]` and `id()` |
