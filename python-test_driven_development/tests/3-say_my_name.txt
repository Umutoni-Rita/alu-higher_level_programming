Using ``say_my_name``
---------------------

Import the function:

    >>> say_my_name = __import__('3-say_my_name').say_my_name

First and last name:

    >>> say_my_name("John", "Smith")
    My name is John Smith

    >>> say_my_name("Walter", "White")
    My name is Walter White

Only a first name (the output ends with a space, which doctest
cannot show reliably, so we check the exact text instead):

    >>> import io, contextlib
    >>> buf = io.StringIO()
