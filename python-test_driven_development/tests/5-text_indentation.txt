The ``5-text_indentation`` module
=================================

Using ``text_indentation``
--------------------------

Import the function:

    >>> text_indentation = __import__('5-text_indentation').text_indentation

Two new lines after each '.', '?' and ':', and no leading spaces:

    >>> text_indentation("Hello. How are you? Fine: thanks")
    Hello.
    <BLANKLINE>
    How are you?
    <BLANKLINE>
    Fine:
    <BLANKLINE>
    thanks

Text without any special character is printed as is (no new line added):

    >>> text_indentation("Holberton School")
    Holberton School

Leading and trailing spaces are removed from each line:

    >>> text_indentation("   Hi.   there   ")
    Hi.
    <BLANKLINE>
    there

Text ending with a special character ends with two new lines:

    >>> text_indentation("End.")
    End.
    <BLANKLINE>

An empty string prints nothing:

    >>> text_indentation("")

A non-string raises TypeError:

    >>> text_indentation(12)
    Traceback (most recent call last):
        ...
    TypeError: text must be a string

    >>> text_indentation(None)
    Traceback (most recent call last):
        ...
    TypeError: text must be a string

Missing argument:

    >>> text_indentation()
    Traceback (most recent call last):
        ...
    TypeError: text_indentation() missing 1 required positional argument: 'text'
